# Contributions

This repository is proprietary and is not open for unapproved code
contributions.

Before submitting code, documentation, tests, designs, or other material, get
written approval from the copyright holder. An approved contributor must state
in writing that they either own the contribution or have authority to submit
it, and grant the copyright holder a perpetual, worldwide, irrevocable,
royalty-free right to use, copy, modify, distribute, sublicense, and relicense
that contribution as part of this project.

Do not submit code copied from another project unless its license permits the
intended use and all required notices are supplied. Do not include credentials,
private health data, Garmin responses, or other personal data in a submission.

Maintainers should retain the written approval with the corresponding Git
commit or release record.
