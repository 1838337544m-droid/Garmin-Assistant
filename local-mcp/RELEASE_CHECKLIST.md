# Release checklist

Use this checklist before sharing a source archive, installer, wheel, or other
copy of this project outside the maintainer's computer.

- [ ] Confirm `LICENSE`, `COPYRIGHT.md`, `AUTHORS.md`, and
      `THIRD_PARTY_NOTICES.md` are included unchanged.
- [ ] Review `requirements.lock.txt` and include every required third-party
      license text and notice for the exact bundled dependency versions.
- [ ] Record the version, date, Git commit ID, archive checksum, and release
      destination in `VERSION_HISTORY.md`.
- [ ] Confirm no API keys, access tokens, health data, caches, reports, or
      local configuration files are in the archive.
- [ ] Confirm all non-maintainer contributions have written permission under
      `CONTRIBUTING.md`.
- [ ] Keep one immutable copy of the release archive and its checksum in a
      location you control.
- [ ] Do not describe the project as affiliated with, endorsed by, or an
      official product of Garmin.

This checklist records a practical release process; it is not legal advice.
